# Kundana Lakshmi D — Portfolio

A personal portfolio built around the art of financial clarity: understated navy, ivory and gold, an animated financial globe, and an interactive view of planning, performance and control.

**Website:** https://kundanalakshmi.github.io/

## Content and editing

- `index.html` contains the profile, ABB experience, education, recognition and contact details.
- `style.css` controls the visual design, responsive layouts, motion and print styles.
- `app.js` handles navigation, the Clarity Lens, scroll reveals and email copying.
- `assets/Kundana_Lakshmi_D_Resume.pdf` is the supplied résumé.
- `assets/social-preview.png` is the social sharing image.

The profile is based on the supplied résumé. The animated globe is decorative; it does not represent actual business data. No company financial information, client outcomes or performance claims have been invented.

## Hosting

The site is plain HTML, CSS and JavaScript, hosted on GitHub Pages from the `main` branch and repository root. No build step, backend or external hosting is required. Changes pushed to `main` are published by GitHub Pages.

For local preview, serve this directory with any static HTTP server, for example:

```sh
python -m http.server 8000
```

Then open http://localhost:8000/.

## Design and accessibility

- Responsive layouts for phones, tablets and desktops.
- Keyboard navigation, labelled controls, accessible tabs and a skip link.
- Reduced-motion support and content that remains readable without JavaScript.
- Email and LinkedIn links; no analytics or third-party data collection.
- Self-hosted Cormorant Garamond and Manrope fonts. Their SIL Open Font License notices are included in `assets/fonts/`.

The portfolio is a personal site and is not an official ABB website.
